# Catálogo de recursos académicos

## Descripción
Proyecto que representa la estructura inicial de un sistema para registrar y consultar recursos académicos.

## Objetivo
Preparar la estructura, documentación y configuración inicial del proyecto para su desarrollo posterior.

## Estructura general
- app/: código principal de la aplicación.
- data/: información de los recursos.
- docs/: documentación del proyecto.
- tests/: pruebas del sistema.

## Tecnologías utilizadas
- Python
- Git
- GitHub
- Visual Studio Code

## Preparación del entorno
1. Crear un entorno virtual con `.venv`.
2. Activar el entorno virtual.
3. Instalar las dependencias con `pip install -r requirements.txt`.

## Dependencias
- requests
- rich
